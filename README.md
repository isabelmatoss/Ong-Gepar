MVP — Site de Adoção Responsável de Animais

1. O que é um MVP?
MVP (Produto Mínimo Viável) é a primeira versão de um projeto que reúne apenas as
funcionalidades essenciais para atender ao seu objetivo principal. Em um projeto web, consiste em
criar uma interface inicial funcional, priorizando elementos como layout, navegação e estrutura
básica.
Desta forma, é possível apresentar uma ideia do projeto, testar sua usabilidade e validar o conceito
antes de implementar recursos mais complexos. O objetivo é desenvolver uma versão inicial enxuta,
funcional e pronta para evoluir conforme as necessidades dos usuários.

2. Definição do nosso MVP

Qual é a principal interação do usuário?
A principal interação será explorar os animais disponíveis para adoção e 
entrar em contato com a Ong Gepar. A página permitirá conhecer os animais por 
meio de fotos e informações, além de oferecer formas de contato com a instituição.

Quais telas são realmente possíveis?
O MVP terá uma única página (landing page), organizada nas seguintes seções:
*Logo da Instituição com a frase de apresentação.
*Vitrine de animais disponíveis para adoção (com possibilidade de ampliação futura).
*Botões Ancora.
*Guia de adoção responsavel em pdf.

Qual informação precisa aparecer?
A página apresentará apenas as informações essenciais para incentivar a adoção ou a ajuda ao bem estar animal, 
como fotos dos animais, nome, idade aproximada, porte,descrição breve,contato para adoção.
Quais ações o usuário precisa realizar?
Visualizar os animais disponíveis para adoção e demonstrar interesse por um animal por meio de cadastro.
Entrar em contato com o bem estar animal.

Existe navegação?
Sim. O site terá um menu simples e intuitivo, com links diretos para as seções da página.
